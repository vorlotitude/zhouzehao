## 1. 角色概述

一名年轻男性创作者形象。视觉气质定位于"新中式 × 都市街头"的克制碰撞：上身保留中式立领盘扣的东方线条，下装与鞋履以现代直筒牛仔和厚底运动鞋收束，形成传统与当代、formal 与 casual 的反差。整体人物服务于网站的黑白极简叙事。

## 4. 发型

- 发色：黑色（纯黑 #111111 级，近墨）。
- 长度：中长发，发梢覆盖颈后，长度及后颈中部。
- 纹理：微卷、蓬松、有层次，顶部有一定体积感，发尾自然外翘 / 内收并存的松散状态。
- 打理感：自然、有造型但不过度刻意，符合"松弛创作者"基调。
- 三面对应：
  - 正面：中分 / 略偏的分缝，两侧发量匀称，鬓角自然。
  - 背面：发量从头顶向颈后集中堆积，形成后部层次（这是发型辨识度的主要视角）。
  - 后侧 3/4：可见发尾的整体厚度与颈后收型。

## 5. 五官与面部

- 年龄段：20 后半的年轻男性。
- 肤色：偏白皙 / 中等偏亮，冷调不明显，建模材质建议中等明度肤色。
- 眉形：自然平直，稍有挑度，衬托方向感。
- 眼：单眼皮偏内双，眼神直接、中性，兼有专注（作品叙事）与松弛（街头感）。
- 鼻梁 / 唇：线条干净利落，鼻梁挺、唇形薄，整体偏清晰轮廓。
- 表情基准：中性、少情绪，作为作品的"静默主体"；不赋予夸张五官特征，保持写实克制的数字肖像感。

> 五官属"特征性弱、气质性强"项——建模时以像真为优先，不夸张。

## 6. 服装（定型造型）

| 部位 | 型号 | 色值 | 版型 / 细节 |
| --- | --- | --- | --- |
| 上衣 | 黑色中式立领盘扣上衣 | 黑（#111 / #151515） | 立领、领口随形；前襟中线分布 3 枚盘扣（金属色圆柱结）；前胸左侧白水墨竹枝刺绣；直身微松剪裁，落肩长袖，衣长及中髋；袖口简洁收束 |
| 下装 | 浅蓝色直筒牛仔裤 | 浅蓝灰（褪色洗水 #A9B4C0 系） | 直筒 / 微宽松腿型，脚踝处轻微堆叠；中度洗水做旧，无破洞装饰 |
| 鞋 | 白色厚底运动鞋 | 白（#F5F5F5） | 厚底增高设计，鞋舌与后跟有墨绿色（橄榄绿 #5A6B4A 系）点缀；现代复古运动鞋款 |

- 层次感口诀：**上重（黑）→ 中灰（浅蓝牛仔）→ 下亮（白鞋）→ 局部点睛（墨绿点缀）**。
- 版型要点：上衣落肩 + 直筒牛仔 + 厚底鞋的"体积 / 收束 / 厚实"三层节奏。
- 衣身刺绣仅存在于正面左胸，背面保持干净，无额外图案。

## 7. 配饰

- 无显性配饰（无项链 / 耳饰 / 手链 / 头饰）。
- 保持"克制"，配饰不作为人物辨识元素；如未来确需增加，先在本文档登记再改动。

## 8. 颜色与黑白关系

色彩体系收敛为 5 个基调：

1. 黑（上衣、发）：视觉权重最高的重色。
2. 白（鞋、刺绣）：提亮点缀。
3. 浅蓝灰（牛仔）：中间过渡灰调。
4. 墨绿（鞋点缀）：唯一低饱和的彩色点睛，克制、不喧宾夺主。
5. 米 / 肤色（皮肤、背景衬色）：中性底。

黑白关系（灰度视角）：
- 人物主体以"深（上衣发）— 浅（鞋）— 中（牛仔）"三段灰度形成剪影辨识。
- 背景留白以米白 / 中性灰为主，人物由此跳出，符合网站整体黑白极简的视觉语言。

## 10. 建模 / 替换时不可妥协项（硬约束）

1. 服装层次不删减，缺失任何一层即不成立。
2. 中式立领 + 盘扣 + 左胸竹枝刺绣为上衣的辨识核心，三者不可舍。
3. 发色 / 纹理（黑、微卷中长、颈后堆叠）不可更改为其他发型。
4. 无配饰的克制原则不变。
5. 黑白灰为色彩基调，墨绿仅限鞋部点缀，不得扩散到全身。
6. 忠于"写实、修长、松弛"的人物气质，不夸张化。
